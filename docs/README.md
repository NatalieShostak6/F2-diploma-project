## Нефункціональні вимоги (NFRs Matrix)

Зведені технічні обмеження проєкту. Повна матриця зі способами перевірки — у [1_analysis.md](1_analysis.md#153-нефункціональні-вимоги-nfrs).

| ID | Категорія | Обмеження |
| --- | --- | --- |
| NFR-01 | Продуктивність | p95 API latency ≤ 200 ms @ 500 RPS (створення публікації) |
| NFR-02 | Продуктивність | p95 ≤ 150 ms @ 500 RPS (стрічка, 20 записів); cache hit ratio ≥ 80 % |
| NFR-03 | Продуктивність | WebSocket delivery: median ≤ 100 ms, p95 ≤ 250 ms @ 1000 connections |
| NFR-04 | Асинхронна обробка | p95 постобробки 10 зображень ≤ 30 s; відхилення TTL-задачі ≤ 60 s |
| NFR-05 | Масштабованість | Real-Time gateway → 4 instances без втрати подій (Redis Pub/Sub adapter) |
| NFR-06 | Надійність | Availability ≥ 99,5 % / місяць |
| NFR-07 | Відмовостійкість | 5 retries, exponential backoff, dead-letter queue; recovery scan ≤ 2 min |
| NFR-08 | Резервне копіювання | PostgreSQL daily backup + WAL archiving; RPO ≤ 15 min, RTO ≤ 1 h |
| NFR-09 | Безпека | OAuth 2.0 / OIDC, signed JWT (RS256), access 15 min / refresh 30 d, TLS 1.3, Argon2id |
| NFR-10 | Комплаєнс | 100 % EXIF stripping; GDPR Art. 17 (≤ 30 d), Art. 20 (JSON export) |
| NFR-11 | Якість коду | Trivy: no High/Critical; coverage ≥ 70 %; SonarCloud Quality Gate passed |
| NFR-12 | Інфраструктура | Docker для всіх компонентів; `docker compose up`; CI build ≤ 10 min |
| NFR-13 | Спостережуваність | 100 % запитів із correlation id; експорт метрик черг ≤ 15 s |

## Угоди ведення документації

- Кожен розділ наповнюється в окремій гілці виду `feature/<назва-розділу>` з наступним Pull Request у `main`.
- Повідомлення комітів оформлюються за специфікацією [Conventional Commits](https://www.conventionalcommits.org/).
- Архітектурні рішення фіксуються у форматі ADR (MADR) і не змінюються заднім числом — застаріле рішення позначається як `Superseded`.
- Діаграми зберігаються у текстовому вигляді (PlantUML, Structurizr DSL) поруч із відповідним розділом.
- Англомовні технічні терміни наводяться мовою оригіналу без транслітерації.
